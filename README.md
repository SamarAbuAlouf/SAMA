#  Academic Management System (SAMS)

A robust and interactive Command-Line Interface (CLI) application built with Python for managing student records, tracking academic performance, and visualizing grades across multiple core subjects.

---

##  Features

- **Secure Authentication:** PIN-protected login system with a limited number of retry attempts.
- **Student Management:** Add new students and input grades for 4 core subjects (*Programming, Data Science, Database, and Artificial Intelligence*).
- **Validation Controls:** Built-in input validation ensuring all grades fall within the valid range (0–100).
- **Safe Deletion:** Search and remove students by their exact name with confirmation prompts.
- **Data Visualization:** Generate clear, comparative Matplotlib charts displaying subject-wise grades alongside class averages.
- **CSV Data Export:** Export the complete database of student records into a structured CSV file using Pandas.
- **Styled CLI Output:** Enhanced terminal text formatting using `termcolor`.

---

##  Tech Stack

- **Python** (Core Logic & Control Flow)
- **Pandas** (Data Manipulation & CSV Export)
- **NumPy** (Numerical & Mathematical Operations)
- **Matplotlib** (Data Visualization & Plotting)
- **Termcolor** (CLI Styling)
